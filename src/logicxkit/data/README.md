# logicxkit/data — packaged record templates and native donors

Generated by `bin/regen_data.py` from the public golden corpus (Logic's own saves of a blank
project, `bin/run fetch-corpus`). Only Logic's own structures live here: record templates for a
fresh track, a section, a send and a stack, and donor slots for Logic's native plug-ins. No
third-party plug-in state, no AU parameter tables (`resources/data/README.md`). The data root
(`LOGICXKIT_DATA`) takes precedence over anything here.

`rba-sequence-12.3.1.json` is the one file not from the corpus: the RBA Sequence triple and
the flex marker block shapes Logic writes on an audio quantize, taken from a tracking take
with every per-region field zeroed (`services/flexmarkers.py` sets them). `regen_data.py`
leaves it alone.
